## 1. Plan, credits, prices, terms

**Website plans.** The core site is free and stays free (US imports dataset, company search, HS Code Explorer, bookmarks). Paid plans add US exports, US customs clearance, Mexico imports/exports, Power Query, Advanced Search, **Supplier Search**, Data Enrichment, Yeti AI; the API is "credit-based" and sold separately from any plan. The footer "Pricing" link goes to a lead-capture survey (`/survey/workflow-survey`); no public price for the website plans was found, only "Manage subscription" behind the account menu and an Enterprise contact address. Paid-plan downloads: unlimited count, **up to 25,000 rows per file** (CSV/XLSX; charts as JPG/PNG/SVG). Searches: "basically unlimited" within the Human Usage Policy.

**API credits ("data credits").** Pay-as-you-go at `/credits-checkout`: **$0.090 per credit, minimum 100 credits ($18)**; volume tiers 5,000 → $0.075, 10,000 → $0.060, 25,000 → $0.045, 50,000 → $0.040, 100,000 → $0.035, Enterprise over 100,000. Credits do not expire on any page read. The key lives at `My Account → Settings → API Credits Settings`; sent as `IYApiKey: <key>` or `Authorization: Bearer <key>`; base URL `https://data.importyeti.com`, routes under `/v1.0`. Every paid response carries `requestCost` and `creditsRemaining`; out of credits is **HTTP 403 "Not enough credits"**; bad key 401; no such record 404. Rate limits are "only limited by credits, so there is no usage cap" (FAQ "What are the API limits?").

**What one supplier costs (cost table at docs.importyeti.com/docs/credits).**

| Endpoint | Credits | Note |
| -- | -- | -- |
| `GET /v1.0/supplier/search?name=…` | **Free** | 0.1 per record only if used as the primary data source without a follow-up data call |
| `GET /v1.0/supplier/{slug}` | **1 per record** | full profile, 24 fields (§2) |
| `GET /v1.0/supplier/{slug}/bols` | 1 per 10 records | returns **BOL numbers only** |
| `GET /v1.0/bol/{number}` | 0.1 per BOL | one full shipment record |
| `GET /v1.0/powerquery/us-import/bols?supplier=<slug>` | 1 per 10 records | full shipment rows, 30 filters incl. `supplier_country`, `start_date`, `end_date`, `hs_code`, `bol_type`; `fields=` trims payload not price |
| `GET /v1.0/powerquery/us-import/suppliers?supplier_country=Bangladesh` | 1 per 10 records | ranked supplier list with slug, aliases, addresses, HS buckets, ports, `total_shipments`, `doc_count` |
| `GET /v1.0/database-updated` | Free | last refresh date |

So one Bangladesh supplier, profile + its last 100 shipments via PowerQuery = **1 + 10 = 11 credits ≈ $0.99** at the entry tier (≈ $0.39 at 100k). Profile alone = 1 credit. The `/bols` + `/bol/{n}` route costs 0.2 per shipment and is the wrong way round; PowerQuery is the one to use.

## 2. Shape of one Bangladesh supplier page (Babylon Garments, `/supplier/babylon-garments`, free plan)

- **Identifier is the URL slug** (`supplier/babylon-garments`), lower-case hyphenated; the API says to resolve a name through `/supplier/search` and use the `key` it returns. Display name "Babylon Garments" (no legal suffix). The page title is name + first address.
- **Header**: name · type "Supplier" · Name / Address toggle · Save / Bookmarks · address as filed on the BOL — here `2-B/1 Darussalam Road Mirpur Dhaka Dhaka-1216 Bangladesh A/C- Mol Consolidation Service Ltd` (forwarder text is part of the address string) · **"Also imports under 4 names and 9 addresses · View list"** · website · "Source: U.S. Customs and Border Protection · ImportYeti synced 09/16/2026" · **Last Shipment Spotted 09/14/2026** · **Total Sea Shipments 437** · Avg. TEU per Shipment 2.62 · Avg. TEU per Month 6.78 · Est. Shipping Spend $239,411.26 "(14% coverage)".
- **Aliases** ("The organization is also known as"): Babylon Garment · Babylon Garment Ltd · Babylon Garments Limited · Babylon Garments Ltd — spelling variants of the shipper name, grouped by ImportYeti; the 9 addresses are the address strings seen on BOLs. Matching to a company name is therefore **string-variant grouping plus address**, no registration number, no BGMEA id.
- **Total Sea Shipments Over Time**: monthly bar chart Jan 2015 → Sep 2026, JPG download, "Plot events".
- **Customers** (CSV): columns **Customer (name + city, country) · Shipment Activity (date range) · Total Shipments · Product Descriptions (category chips + a truncated description + "HS Codes: (6205.20, 6205.90 …)")** · "See all bills of lading with this company". Toggle "Hide internal customers and omitted data (2)". Rows on this page: "Export Import" (consignee missing in the filing, 109) · Joules USA 41 · Kmart 34 · Nautica Men's Sportswear 23 · LF Sourcing Millwork 22 · Supreme International 20 · Marshalls of MA 11 · "Show More". **All customers are US consignees** — this is the US import dataset only.
- **Cost Structure**: currency card (BDT rate, "Potential loss for every $10,000 spent", "Currency Rating: A").
- **Annual Exporting Frequency**: shipments per calendar month, with a 5-band legend.
- **HTS Codes Pulled from Product Descriptions (Top 10)**: table HTS Code (10-digit, e.g. 6205.20.2051) · Description · a sample BOL number · the raw product description; "Unlock the full shipment list in Power Query →" (paid). Below it a **Country** table of the shipper's origin ports: Bangladesh 407 · Singapore 24 · Sri Lanka 5 · Malaysia 1 (transhipment, not destination).
- **Most Recent Sea Shipments** (CSV, "Unlock the full shipment list in Power Query →"): columns **Date · Bill of Lading (house number with "H" badge over the master number with "M"; a direct-to-carrier row shows "IR · Direct to Carrier") · Customer (name + city, country) · Weight kg · Quantity ctn · No. of Containers · Description · Est. Freight Cost** (lane, "No Data" or a dollar figure). About 12 rows visible on free; one BOL is tagged "(free)". Dates on the site are **MM/DD/YYYY**; the API returns **DD/MM/YYYY** in most fields (`mostRecentShipment: "29/03/2024"`) and MM/DD/YYYY in some samples — parse defensively.
- **Other addresses, names and contact information** (CSV): counters "Captured Company Contact Info 6 · Other addresses 9 · Other names 4 · Other websites 1"; **Emails 4 · Unlock** (columns Email · Last date captured · Shipments · Companies using this email · Address) and **Phone numbers 2 · Unlock**, masked on free. We never take these (contact PII is out of scope for the shipments layer and would breach our own PII rule).
- **Not on the page**: destination countries other than the US, any register id, certifications, factory data, year founded, workers.

**API profile (`GET /v1.0/supplier/{slug}`, 24 fields):** `title` · `also_known_names[]` · `address` · `address_country` · `address_country_code` · `website` · `other_websites[{website,frequency}]` · `phone_number` · `total_shipments` · `country` · `country_code` · `carriers_per_country{}` · `container_types{}` · `containers[]` · `containers_load{less,full}` · `lane_permutations[{exit_port,exit_port_country,entry_port,entry_port_country,shipments,weight,teu}]` · `date_range{start_date,end_date}` · `time_series{date:{shipments,weight,teu}}` · `hs_codes[{hs_code,shipments,shipments_12m,weight,teu,description,children[]}]` · **`companies_table[{company_name,company_address,company_address_country,key,total_shipments_company,shipments_12m,first_shipment,most_recent_shipment,…}]`** · `recent_bols[]` · `total_shipping_cost` · `avg_teu_per_shipment{}` · `avg_teu_per_month{}`. `fields=` / `exclude=` trim the payload (same price).

**API shipment row (`/powerquery/us-import/bols` or `/bol/{number}`), the fields we keep:** `bol_number` · `bol_type` (R regular / H house / M master) · `master_bol_number` · `arrival_date` · `company_name` (US consignee) · `company_link` · `company_country` · `hs_code` (6-digit) · `hs_code_description` · `product_description` · `weight` (kg) · `quantity` · `quantity_unit` · `teu` · `exit_port` · `entry_port` · `supplier_name` · `supplier_link` · `supplier_country` · `supplier_address_country` · `shipping_cost` (estimate) · `cif` ("0" on every sample — not a real CIF). Also present and **not** kept: `company_contact_info`, `supplier_contact_info`, `notify_party_*`, geocodes, containers, vessel.

## 3. Search behaviour

- Website search box "Find Any Company's Suppliers" → `/search?q=<text>&page=1`. Tabs **Companies & Suppliers · Addresses · Product Finder by HS Code · Product Finder**; filters **Type (Both / Suppliers / Companies) · Most Recent Shipment · Total Shipments · dataset (U.S. Imports)** · "Include related companies" · Advanced Search (operators `""`, `|`, `+`, `-`, `*`, `()`). **No country filter on the site**; the Addresses tab searches the address string, so "Bangladesh" works as a text filter. Query "Ha-Meem Denim" returned "1–10 of 1,420 business profiles built from 62,241 shipments", 10 per page, 142 pages, ranked by relevance (Ha Meem Denim Mawna · Ha Meem Design · Ha Meem Apparels · Ananta Denim Technology · …).
- **Each result row shows, without opening the page**: name · type · address · **Total Shipments** · **Most recent shipment** (date) · **"Also Exports Under N names, M addresses"**. No top customer on the row.
- **API search (`/supplier/search`, free)**: `name` / `phone` / `website`, `page_size` (default 10), `offset`; each hit = `title · countryCode · type · address · totalShipments · mostRecentShipment · topCompanies[] (up to 4 names) · key (slug)`. `countryCode` lets the caller keep only `BD` hits. This is what the stub job needs: shipment count hint, last-seen date, and the slug, at zero credits.
- **Country-wide listing** (for a one-off stub backfill instead of per-name search): `/powerquery/us-import/suppliers?supplier_country=Bangladesh&page_size=…` — paid, 1 credit per 10 suppliers, `data.totalSuppliers` gives the population.

## 4. API / export products

- API docs: https://docs.importyeti.com (26 endpoints: BOL 1 · Companies 3 · Suppliers 3 · Products 2 · PowerQuery 16 · Database 1), Swagger UI, MCP server, TOON response format. Datasets: US imports (from 2015), US exports (2015), Mexico imports/exports (2021), US customs clearance (2023). BOL data appears **after** arrival (no forward visibility). Free sample endpoints on `/yeti-api` (Walmart profile, one BOL).
- Export from the site: Power Query downloads, 25,000 rows per file, paid plan; CSV buttons on every supplier-page table.
- Bulk/feed: explicitly not Purchased Data — "a separate agreement" via sales.
- No free export sample was found; the docs' example responses (above) are the field reference.

## 5. What this means for the handoff (carried into §4.8)

- ImportYeti answers **US bill-of-lading customers and shipments** for Bangladeshi suppliers. It does **not** answer "key export markets": every consignee is in the US (Mexico is a separate dataset). Our "Key export markets" stays "Not on file" unless the founder adds a second provider; the Customers section can say "US buyers on bills of lading".
- Babylon on ImportYeti = 437 US sea shipments; on SourceReady = 3,979 (they merge non-US customs declarations — ASDA, ZPDC, Perry Ellis Mexico rows carried CIF and no B/L). Different numbers for the same factory are expected and must be labelled by provider.
- Slug resolution is the matching problem: `Babylon Garments Ltd.` → search `babylon garments` → pick the `BD` hit whose aliases contain the register name; keep `matched_how` honest (`exact_alias`, `name_only`, `unknown`).

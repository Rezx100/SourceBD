# Fonts

Geist and Geist Mono (variable, woff2) from the SourceBD Design System artifact's
`project/fonts/`, self-hosted so a build never reaches a font CDN. Both are
published by Vercel under the SIL Open Font License 1.1
(https://openfontlicense.org): free to bundle, embed and redistribute; the fonts
may not be sold on their own. Loaded once in `app/layout.tsx` with `next/font/local`.

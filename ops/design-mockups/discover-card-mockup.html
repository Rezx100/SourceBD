Save action — a star doesn't say "you'll be notified of cert/reg changes"

Before — Star / "Save"

Reads as "favorite" — a bookmark for later. Says nothing about the fact that saving quietly enrols the buyer in cert/registration change alerts on this company.

After — Bell / "Follow"

Matches the actual behavior: on by default, notifies on meaningful changes (cert/registration expiry today; more event types later), opt-out anytime from settings. Off-state outline, on-state filled — same toggle pattern as the star had, honest icon.

Label also changes from "Save" / "Saved" → "Follow" / "Following" to match. Hovering (desktop) or long-pressing (mobile) shows a one-line tooltip: "You'll get notified about cert & registration changes on this company. Opt out anytime in Settings." First-follow could show a one-time toast with the same copy so the default isn't a silent surprise.
